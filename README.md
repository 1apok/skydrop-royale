# SKYDROP Royale

Оффлайн королевская битва для iOS на Godot 4.5 (Forward+, Metal): 1 игрок против 5–49 ботов на процедурном острове.

## Режимы
- **Стройка** — стены, полы, лестницы, крыши из дерева/камня/металла, добыча материалов киркой, разрушение и обрушение построек.
- **Нулевая высота** — без строительства, перезаряжающийся сверхщит 50, ускоренный бег и залезание на уступы.

## Графика
Пресеты: Низкие / Средние / Высокие / Ультра / RT.
RT включает SDFGI (программная трассировка глобального освещения), SSR, SSIL, объёмный туман.
На iOS используется апскейлинг MetalFX (пространственный/временной), на ПК — FSR/FSR2.
Все параметры можно менять по отдельности в настройках.

## Боты
Высадка в выбранные точки, лут сундуков и оружия, выбор оружия по дистанции, стрейф, прыжки,
упреждение, защитная стройка (стена + лестница), коробка при лечении, поиск укрытий, реакция на звуки
выстрелов, ротация в зону, пробивание стен киркой. 4 уровня сложности.

## Сборка IPA
### GitHub Actions (без Mac)
1. Залей проект в репозиторий GitHub (ветка `main`).
2. Actions → **iOS IPA** → Run workflow. Через ~15 минут в артефактах будет `SKYDROP-unsigned.ipa`.
3. Подпиши своим сертификатом (Sideloadly, ESign, Feather и т.п.).

Чтобы CI сразу подписывал, добавь секреты репозитория:
`IOS_P12_BASE64` (`base64 -i cert.p12`), `IOS_P12_PASSWORD`, `IOS_PROFILE_BASE64` (`base64 -i profile.mobileprovision`).

### На Mac
```
./ios/build_ipa.sh
# с подписью:
IOS_P12=cert.p12 IOS_P12_PASSWORD=pass IOS_PROFILE=profile.mobileprovision ./ios/build_ipa.sh
```

## Управление на ПК (для теста в редакторе)
WASD, мышь, ЛКМ — огонь, ПКМ — прицел, Пробел — прыжок, Ctrl — присесть, R — перезарядка, E — взять/открыть,
1–5 — слоты, F — кирка, Q — режим стройки, Z/X/V/B — стена/пол/лестница/крыша, T — материал, M — карта, Esc — пауза.
